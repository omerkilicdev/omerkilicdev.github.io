Inside a vortex-panel flapping-wing simulation

Denda Lab, Rutgers MAE
Diagrams from one run: four wings, 12 time steps

Before changing the lab’s unsteady vortex-panel code I drew what each part of it computes, using the numbers from one run of four flapping wings over 12 time steps: the wing mesh, the stroke, how the edges are shed into a wake, the linear system for the circulations, and the velocity the wake induces on itself. Pick a diagram below; the 3D ones can be played, scrubbed and rotated with the mouse or a finger.
